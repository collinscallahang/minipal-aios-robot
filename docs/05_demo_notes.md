# 演示说明

## 演示目标

用最短的展示流程，让评审看到 `MiniPal` 具备完整的“输入 - 决策 - 输出”闭环。

## 推荐演示顺序

先打开https://raw.githack.com/collinscallahang/minipal-aios-robot/codex-ai-bridge-access/simulation/index.html
这个页面是本项目的交互仿真 Demo，用于替代实体硬件演示。

### 场景 1：按钮唤醒

1. 展示仿真器中的机器人处于 `IDLE` 状态，LED 为待机蓝。
2. 点击“按钮唤醒”。
3. 观察状态机从 `IDLE` 进入 `WAKE`，随后执行 `GREET` 或 `THINK`。
4. 观察舵机角度、LED 状态、蜂鸣器状态和 UART 日志变化。

这一段重点说明：

- 输入来自按钮
- 状态从 `IDLE` 切到 `WAKE`
- 主机侧 AI 桥接可返回 `GREET` 或 `THINK`

### 场景 2：距离告警

1. 拖动距离滑块，让前方距离低于阈值。
2. 机器人进入 `ALERT`。
3. LED 变红，蜂鸣器告警，舵机抬头或转向警觉姿态。

这一段重点说明：

- 距离感知是实时本地控制
- 告警状态不依赖网络
- 这是为了保证响应速度和稳定性

## 推荐讲解口径

- “我把高层 AI 决策和底层实时控制做了分层。”
- “按钮触发和距离避障构成了一个最小可用闭环。”
- “前脸的双探头既是传感器，也是桌宠视觉里的眼睛。”
- “当前版本用浏览器仿真器呈现实体系统的控制逻辑，后续接入 ESP32 时可复用同一套状态机和串口协议。”

## 仿真与实体的对应关系

- 页面按钮对应实体顶部按钮。
- 距离滑块对应 HC-SR04 测距结果。
- 机器人转头对应 SG90 舵机输出。
- LED 颜色对应 WS2812 灯效。
- 日志窗口对应 ESP32 与主机之间的 UART 通信。
