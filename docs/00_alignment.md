# 项目定稿

本文档用于记录 `MiniPal` 的最终方案选择，便于在文档、代码和结构设计之间保持一致。

## 项目定位

- 项目名：`MiniPal`
- 机器人定位：桌宠型桌面陪伴 / 提醒机器人
- 外观风格：前脸使用传感器双探头形成“眼睛”视觉
- AI 方案：默认本地规则，保留云端 API 扩展
- 演示输入方式：按钮触发 + 距离感应
- 完成度目标：文档 + 代码 + 结构图 + 浏览器仿真原型

## 最终模块选择

- MCU：`ESP32 DevKit`
- 输入：`按钮 + HC-SR04 距离传感器`
- 输出：`SG90 舵机 + WS2812 RGB LED + 蜂鸣器`
- AI 接入：`Python 主机桥接，默认本地规则，可切换云端 API`
- 通信：`USB UART`
- 供电：`USB 5V` 或 `5V 移动电源`

## 最终结构参数

- 外形尺寸：`100 x 90 x 70 mm`
- 壁厚：`3 mm`
- 结构形式：双层壳体
- 模块布局：
  - 前脸：HC-SR04 传感器
  - 顶部：按钮
  - 上层：舵机和头部动作平台
  - 中层：ESP32 主板
  - 下层：电源区 / 电池托盘

## 定稿原因

- 桌宠外观更容易形成直观展示效果。
- 传感器双探头天然适合作为“眼睛”，外观和功能可以合并。
- 本地规则负责实时反应，云端 AI 负责高层策略，系统层次更清楚。
- 100 x 90 x 70 mm 的尺寸更紧凑，也更容易在桌面场景下解释结构布局。
