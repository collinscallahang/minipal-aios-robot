# 结构设计说明

## 文件

- [minipal_structure_layout.svg](minipal_structure_layout.svg)：顶视 + 侧视 + 正视布局草图，适合作业截图
- [minipal_case.scad](minipal_case.scad)：可继续修改的 OpenSCAD 壳体文件

## 默认尺寸

- 外形尺寸：`100 x 90 x 70 mm`
- 壁厚：`3 mm`
- 建议打印层高：`0.2 mm`
- 建议喷嘴：`0.4 mm`

## 模块布局

- 前脸中央：距离传感器，保证前向探测方向稳定
- 顶部中央：按钮
- 上层内部：舵机和头部转轴
- 中层：ESP32 主板
- 底部：电池或移动电源固定区

## 为什么这么设计

- 传感器在前面，数据含义最直观。
- 传感器双探头可直接形成桌宠“眼睛”，减少额外装饰件。
- 舵机在上层，更容易形成“头部动作”。
- 电池放在下层，可以压低重心，减少舵机动作时的晃动。
- 主板居中，布线更短，串口和电源接口也更容易留孔。

## 如何保证结构稳定

- 让最重的模块尽量靠底部。
- 壳体四角留圆角，降低应力集中。
- 舵机固定区域做局部加厚。
- 传感器窗口不要过深，避免探测受遮挡。

## 如果 3D 打印，哪里容易失败

- 传感器开口上方的桥接容易下垂。
- 舵机安装位如果壁厚太薄，螺丝锁紧时容易裂。
- 大平底面可能翘边，最好加圆角或底边倒角。
